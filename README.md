# Jogo de Plataforma 2D
Este projeto consiste é um protótipo de jogo de plataforma 2D, desenvolvido em C# com a Unity 6, como atividade da disciplina de Desenvolvimento de Jogos Digitais.

O objetivo é aplicar conceitos de desenvolvimento de jogos digitais, implementando mecânicas de movimentação, detecção de colisões e simulação física.

O protótipo apresenta um personagem em estilo pixel art, controlado pelas teclas A/D ou pelas setas direcionais para movimentação horizontal, além da barra de Espaço para execução de saltos. A mecânica de salto utiliza o método Physics2D.OverlapCircle para verificar o contato com o solo, impedindo saltos consecutivos enquanto o personagem estiver no ar.

O cenário é composto por plataformas distribuídas em diferentes alturas, proporcionando a exploração das mecânicas implementadas.
